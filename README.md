# ZakFit

Application iOS de suivi santé : repas, activités physiques, objectifs.
Projet ECF — Advanced Apple Foundation Programme (20 nov → 11 déc 2026).

## Stack
- iOS : SwiftUI (MVVM), Swift Charts
- Backend : Vapor (Fluent, JWT, CORS)
- Base de données : MySQL

## Structure du dépôt
| Dossier | Contenu |
| --- | --- |
| `docs/` | Livrables de conception |
| `database/` | Script SQL et données fictives |
| `ZakFitAPI/` | API Vapor |
| `ZakFitApp/` | Application iOS |
